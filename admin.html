El panel necesita el servidor

Las ventas se guardan en el servidor, por eso el panel no funciona abriendo el archivo directamente. En la terminal ejecuta:

node server/server.js

y abre http://localhost:3000/admin.html

Datos de demostración. Estas cifras incluyen ventas de prueba. Bórralas antes de vender de verdad con node server/seed.js --clear.
